# Полка — визуальный конструктор стеллажей с AI-навигацией

Сервис помогает покупателю найти товар в магазине. Администратор собирает простую
схему торгового зала, а Telegram-бот отвечает словами, на каком стеллаже и какой
полке находится нужный товар.

Например, на вопрос «Где молоко?» бот отвечает: «Молоко — стеллаж „У входа“,
вторая полка сверху, слева». При необходимости покупатель может запросить схему
магазина картинкой.

## Как это работает

1. Администратор открывает веб-редактор и добавляет стеллажи на 2D-карту зала.
2. Для каждого стеллажа задаётся количество полок и ориентир — например, «справа
   от входа».
3. Категории товаров перетаскиваются на нужные полки. Порядок блоков слева
   направо тоже сохраняется.
4. Все изменения автоматически попадают в структурированную базу данных.
5. Покупатель пишет боту вопрос. Сервис находит товар в базе и формирует точный
   словесный маршрут: стеллаж, полка и сторона.
6. AI помогает разобрать сложные или ошибочные названия товаров, но не придумывает
   расположение. Стеллаж и полка всегда берутся из базы.
7. Если AI недоступен, ответ формируется без него. Если товара нет на схеме, бот
   честно сообщает об этом и предлагает уточнить название.

Покупателю не нужно смотреть на схему: основной формат ответа — текст. Картинку
со схемой магазина можно запросить отдельно.
